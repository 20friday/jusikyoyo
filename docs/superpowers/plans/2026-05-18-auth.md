# SSR 전환 + Supabase 인증 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Astro 정적 사이트를 SSR로 전환하고 이메일/구글/네이버 로그인·회원가입 시스템을 구축한다.

**Architecture:** `@supabase/ssr` + Astro 미들웨어 방식. 미들웨어에서 모든 요청마다 쿠키 기반 세션을 확인해 `Astro.locals.supabase / session / user`로 주입. 소셜 로그인은 서버사이드 API 라우트에서 OAuth URL을 생성해 리다이렉트. 콜백은 `/auth/callback`에서 `exchangeCodeForSession`으로 세션 교환.

**Tech Stack:** Astro v6 SSR, `@astrojs/vercel`, `@supabase/supabase-js`, `@supabase/ssr`, Supabase Auth (Email + Google OAuth + Naver Custom OAuth)

```ts
import { defineMiddleware } from 'astro:middleware';
import { createSupabaseServerClient } from './lib/supabase';

export const onRequest = defineMiddleware(async (context, next) => {
  const supabase = createSupabaseServerClient({
    getAll: () =>
      context.cookies.getAll().map((c) => ({ name: c.name, value: c.value })),
    setAll: (cookiesToSet) =>
      cookiesToSet.forEach(({ name, value, options }) =>
        context.cookies.set(name, value, options ?? {})
      ),
  });

  const {
    data: { session },
  } = await supabase.auth.getSession();

  context.locals.supabase = supabase;
  context.locals.session = session;
  context.locals.user = session?.user ?? null;

  return next();
});
```

Supabase 대시보드 → SQL Editor에서 실행:

```sql
CREATE TABLE public.profiles (
  user_id uuid PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  role text NOT NULL DEFAULT 'user' CHECK (role IN ('user', 'admin')),
  subscription_status text NOT NULL DEFAULT 'trial'
    CHECK (subscription_status IN ('trial', 'paid', 'expired')),
  trial_expires_at timestamptz NOT NULL DEFAULT (now() + interval '3 days'),
  created_at timestamptz NOT NULL DEFAULT now()
);

ALTER TABLE public.profiles ENABLE ROW LEVEL SECURITY;
```

Expected: `public.profiles` 테이블이 생성됨. Table Editor에서 확인 가능.

- [ ] **Step 2: DB trigger 생성**

```sql
CREATE OR REPLACE FUNCTION handle_new_user()
RETURNS trigger AS $$
BEGIN
  INSERT INTO public.profiles (user_id, role, subscription_status, trial_expires_at)
  VALUES (
    NEW.id,
    'user',
    'trial',
    NOW() + INTERVAL '3 days'
  );
  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;

CREATE TRIGGER on_auth_user_created
  AFTER INSERT ON auth.users
  FOR EACH ROW EXECUTE FUNCTION handle_new_user();
```

- [ ] **Step 4: Google OAuth 설정 (Supabase 대시보드)**

1. Authentication → Providers → Google → Enable
2. Google Cloud Console에서 OAuth 2.0 클라이언트 생성
   - 승인된 리디렉션 URI: `https://<supabase-project>.supabase.co/auth/v1/callback`
3. Client ID, Client Secret을 Supabase Google provider에 입력 후 저장

- [ ] **Step 5: Naver Custom OAuth 설정 (Supabase 대시보드)**

1. 네이버 Developers(developers.naver.com) → 애플리케이션 등록
   - 사용 API: 네이버 로그인
   - 서비스 환경: PC 웹
   - 서비스 URL: 실제 도메인 (로컬 개발용: `http://localhost:4321`)
   - Callback URL: `https://<supabase-project>.supabase.co/auth/v1/callback`
2. 발급된 Client ID, Client Secret 복사
3. Supabase 대시보드 → Authentication → Providers → Add Custom Provider
   - Provider name: `naver`
   - Authorization URL: `https://nid.naver.com/oauth2.0/authorize`
   - Token URL: `https://nid.naver.com/oauth2.0/token`
   - User Info URL: `https://openapi.naver.com/v1/nid/me`
   - Client ID, Client Secret 입력
   - Scopes: `name email`
4. 저장 후 Supabase가 부여한 Custom Provider ID 확인 (예: `custom:naver`)

```ts
import type { APIRoute } from 'astro';

export const GET: APIRoute = async ({ locals, request, redirect }) => {
  const origin = new URL(request.url).origin;
  const { data, error } = await locals.supabase.auth.signInWithOAuth({
    provider: 'google',
    options: { redirectTo: `${origin}/auth/callback` },
  });

  if (error || !data.url) {
    return redirect('/login?error=auth_failed');
  }
  return redirect(data.url);
};
```

```astro
if (Astro.locals.session) {

let errorMessage = '';

if (Astro.request.method === 'POST') {
  const form = await Astro.request.formData();
  const email = String(form.get('email') ?? '');
  const password = String(form.get('password') ?? '');
```

```astro
  if (password !== confirm) {
```
