# PICK 유료 리포트 페이지 — 디자인 스펙

## 개요

여러 주식 방송을 교차 분석해, 공통 언급 종목·섹터 흐름·방송 간 의견 차이를 하루 단위로 정리해주는 프리미엄 페이지. 무료 글(방송별 요약)과 달리, 방송을 다 보지 않아도 시장 핵심 신호를 빠르게 파악할 수 있게 해준다.

---

## 페이지 경로

`/report` — 메인 피드(`/`)와 별개의 페이지. 초기 MVP에서는 헤더 또는 피드 상단에 진입 버튼을 추가해 연결.

---

## 레이아웃

- **단일 스크롤** 구조. 탭 분리 없음.
- 최대 너비 680px, 모바일 우선.
- 섹션 순서: 히어로 → 공통 언급 종목 → 방송 간 의견 차이 → 섹터 공통 흐름 → 오늘의 투자 인사이트 → 구독 CTA.

---

## 섹션별 상세

### 1. 히어로

- 어두운 배경(#191f28 → #2d3748 그라데이션), 흰 텍스트.
- 날짜 + "PICK 리포트" 라벨 (소문자, 흐린 흰색).
- 오늘 시장 핵심 한 문장 — 굵고 크게 (18px, 900 weight).
- 비교한 방송 수 / 공통 종목 수 뱃지 (반투명 흰 배경 pill).

### 2. 공통 언급 종목

- 무료 공개: 상위 2개 종목 (랭킹 번호 + 종목명 + 언급 방송명).
- 3위 이하: 블러 처리 (blur 강도 점진 증가).
- 블러 영역 아래 "🔒 전체 종목 + 해석 보기" CTA 버튼 (#111 배경).

### 3. 방송 간 의견 차이

- 첫 줄(삼프로TV 해석)만 노출.
- 두 번째 줄부터 blur + 하단 그라데이션 페이드(투명 → #fff).
- PICK 해석 텍스트는 오렌지 색상(#ed781f)이지만 블러 처리.
- "🔒 구독하고 전체 보기" CTA 버튼.

### 4. 섹터 공통 흐름

- 방송 간 의견 차이 섹션과 함께 블러 처리(같은 잠금 영역 안).
- 섹터명 + 한 줄 흐름 요약 형태.

### 5. 오늘의 투자 인사이트

- 전체 블러 + 그라데이션 페이드.
- "🔒 내일 봐야 할 포인트 보기" CTA 버튼.

### 6. 구독 CTA (하단)

- 히어로와 동일한 어두운 그라데이션 배경.
- 제목 + 혜택 한 줄 요약.
- 오렌지 버튼: "월 9,900원으로 시작하기".

---

## 무료 사용자 잠금 방식

- **블러 + 그라데이션 페이드**: 일부 내용을 읽을 수 있게 보여준 뒤, 아래로 갈수록 blur 강도 증가 + 흰색 그라데이션 오버레이로 사라짐.
- 섹션 전체를 가리는 방식(B안)은 사용하지 않음 — 맛보기로 궁금증 유발이 목적.
- 각 잠금 섹션마다 개별 CTA 버튼 배치.

---

## 데이터 구조 (초기 MVP)

초기에는 Supabase 연동 없이 마크다운 파일 또는 정적 데이터로 시작. 리포트는 날짜 기준 하루 1개. 구독 여부는 추후 Supabase Auth + 멤버십 연동.

| 필드 | 설명 |
|---|---|
| `date` | 리포트 날짜 (YYYY-MM-DD) |
| `headline` | 오늘 핵심 한 문장 |
| `shows` | 비교한 방송 목록 |
| `stocks` | 공통 언급 종목 (랭킹, 언급 방송) |
| `comparisons` | 방송 간 의견 차이 (종목별) |
| `sectors` | 섹터 흐름 요약 |
| `insight` | 오늘의 투자 인사이트 |
